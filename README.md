Информационная система управления служебными поручениями

Веб-система для постановки, отслеживания и контроля исполнения служебных поручений сотрудникам. Разработана в рамках производственной практики в Центральной комиссии по выборам и референдумам Кыргызской Республики.

Все данные в репозитории тестовые.


Панель руководителя Карточка поручения

Возможности
Роли: руководитель отдела и сотрудник
Разграничение по отделам: руководитель ставит поручения и видит задачи только сотрудников своего отдела
Поручения: создание, назначение исполнителя, срок, приоритет, статус
Вложения: прикрепление файлов к поручениям
Уведомления внутри системы (прочитано / не прочитано)
Поиск и фильтры на панели по статусу, приоритету и сроку
История изменения статусов поручения
Статистика по отделу на панели руководителя
Месячный отчёт по периоду, сотруднику или всему отделу с выгрузкой в PDF

Запуск проекта
Клонируй репозиторий:
bash
   git clone https://github.com/BSN1405/cec-task-system.git
   cd cec-task-system
Создай и активируй виртуальное окружение:
bash
   python -m venv venv
   venv\Scripts\activate        # Windows
   source venv/bin/activate     # Linux / macOS
Установи зависимости:
bash
   pip install -r requirements.txt
Создай базу данных PostgreSQL.
Скопируй .env.example в .env и впиши настройки подключения к БД и SECRET_KEY.
Примени миграции и создай администратора:
bash
   python manage.py migrate
   python manage.py createsuperuser
Запусти сервер:
bash
   python manage.py runserver
Открой http://127.0.0.1:8000
